# Its Something Good LLC website

Static website for https://itssomethinggood.net

## GitHub Pages
1. Create a public repository, for example `its-something-good-website`.
2. Upload all files from this folder to the repository root.
3. In GitHub: Settings > Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Under Custom domain, enter `itssomethinggood.net`.
7. GitHub will show the DNS records required at your domain registrar.
8. After DNS verifies, enable **Enforce HTTPS**.

Before publishing, make sure `contact@itssomethinggood.net` is an email address you can receive.
